# Bilder

Die Dateien in diesem Ordner sind **Platzhalter** – Ausschnitte aus `layout.jpg`, damit die
Website von Anfang an vollständig aussieht. Sie haben eine niedrige Auflösung und sind nicht
für die Veröffentlichung gedacht.

Zum Austauschen: in TinaCMS unter `/admin` die jeweilige Seite öffnen, beim Bildfeld auf das
Bild klicken und eine neue Datei hochladen. Sie landet automatisch in diesem Ordner.

Empfehlung für neue Fotos: Breite etwa 1600–2000 Pixel, als JPEG gespeichert, Dateigröße
möglichst unter 300 KB.
